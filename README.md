# xpander-ai/homebrew-tap

```bash
brew install --cask xpander-ai/tap/xpander
```

xpander Desktop for macOS (Apple silicon and Intel), signed and notarized by Xpander Inc. The app updates itself;
`brew upgrade --cask xpander` also works.

`Casks/xpander.rb` is written by the xpander Desktop release workflow on every production build
(`electron/scripts/distribution-manifests.mjs` in xpander-app); do not edit it by hand.
